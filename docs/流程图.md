## 2. RAG 系统：检索与回答

```mermaid
flowchart TB
  K["进入 knowledge_node"]
  K --> Urgent{"命中急症安全路径？"}
  Urgent -->|"是"| Fixed["确定性安全回复<br/>跳过检索与模型回答"]
  Urgent -->|"否"| Query["构建检索问题<br/>优先使用规划器分配的医疗子目标"]
  Query --> Embedding["Embedding<br/>问题转为向量"]
  Embedding --> Search["Chroma 相似度检索<br/>最多 5 段，阈值 0.8"]

  Search --> PreFilter["索引预筛<br/>active 状态、生效时间、未过期"]
  PreFilter --> Authority["复核资料范围与发布登记<br/>患者默认 public"]
  Authority --> Clean["清理控制字符、限制片段长度"]
  Clean --> Injection["剔除空正文与明显提示注入片段"]
  Injection --> Available{"还有可用资料？"}

  Available -->|"有"| Context["组装院内资料上下文<br/>保留来源与定位信息"]
  Context --> Clinical{"回答需要本人已存记录？"}
  Clinical -->|"是"| Java["临床摘录工具 → Java<br/>按白名单范围读取患者数据"]
  Java --> Answer["依据院内资料与本轮档案结果回答"]
  Clinical -->|"否"| Answer
  Answer --> Sources["生成回复与来源引用"]

  Search -->|"检索异常"| Web["公开网页搜索 Agent"]
  Available -->|"没有"| Web
  Web --> WebOK{"搜索与回答成功？"}
  WebOK -->|"是"| WebReply["返回公开资料回答"]
  WebOK -->|"否"| Unavailable["返回服务暂不可用提示"]

  Fixed --> Output["返回主流程<br/>final_node 汇合"]
  Sources --> Output
  WebReply --> Output
  Unavailable --> Output
```

## 3. RAG 系统：知识库补充

```mermaid
flowchart TB
  Upload["管理员上传 / 重建资料"]
  Upload --> JavaAuth["Java 校验管理权限"]
  JavaAuth --> Python["转发 Python 知识库接口"]
  Python --> Dedup{"重复提交？"}
  Dedup -->|"是"| Existing["返回已有提交结果"]
  Dedup -->|"否"| Store["保存原文件"]
  Store --> Register["登记文档版本、解析任务<br/>元数据库"]
  Register --> Worker["后台 Worker 领取任务"]
  Worker --> Parse["格式解析<br/>PDF / DOCX / TXT / Markdown"]
  Parse --> Clean["清洗提取结果"]
  Clean --> Classify["判断文档类型"]
  Classify --> Chunk["按文档结构切分"]
  Chunk --> Quality["生成质量评估报告"]
  Quality --> Artifact["保存解析产物与质量状态"]

  Artifact --> Pass{"质量通过？"}
  Pass -->|"是"| Ready["built：可进入发布"]
  Pass -->|"需复核"| Review["人工审核"]
  Review -->|"通过"| Ready
  Review -->|"拒绝"| Rejected["拒绝版本"]

  Ready --> Publish["管理员显式发布"]
  Publish --> Documents["解析产物转为检索片段<br/>附版本、来源、有效期"]
  Documents --> Embed["Embedding 向量化"]
  Embed --> Index["写入 Chroma 待公开索引"]
  Index --> Commit["元数据库登记发布"]
  Commit --> Visible["更新索引状态<br/>active 或 scheduled"]
  Visible --> Retrieval["生效版本供对话检索"]

  Parse -->|"解析异常"| Failure["记录失败与重试状态"]
  Failure -->|"重新领取任务"| Worker
```

## 6. 意图识别流程

```mermaid
flowchart TB
  subgraph Intent["意图识别 · begin_node"]
    Safety["检测急症风险"]
    Conditional{"条件式请求？"}
    Rules["高精度规则匹配"]
    RuleHit{"规则命中？"}
    Jev["优先调用 Jev 多标签分类"]
    JevAvailable{"Jev 配置有效且调用成功？"}
    Ollama["Ollama 本地分类<br/>仅作为 Jev 不通时的兜底"]
    Accept{"结果通过门槛<br/>且无需追问上下文？"}
    Cloud["云端 LLM 结合近期对话分类"]
    Validate["校验输出<br/>无效 JSON 尝试修正一次"]
    Result["取得标签 / 本地降级结果<br/>或固定澄清与范围提示"]
    Guard["急症风险补入 knowledge<br/>记录路由指标"]

    Safety --> Conditional
    Conditional -->|"是"| Cloud
    Conditional -->|"否"| Rules
    Rules --> RuleHit
    RuleHit -->|"是"| Result
    RuleHit -->|"否"| Jev

    Jev --> JevAvailable
    JevAvailable -->|"是"| Accept
    JevAvailable -->|"未配置 / 调用失败 / 服务不可用"| Ollama
    Ollama -->|"调用成功"| Accept
    Ollama -->|"调用失败 / 服务不可用"| Cloud

    Accept -->|"是"| Result
    Accept -->|"不确定 / 需要追问上下文"| Cloud
    Cloud --> Validate --> Result
    Result --> Guard
  end
```
