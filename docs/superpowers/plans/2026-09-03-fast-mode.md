# 快速模式（Fast Mode）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 给患者端聊天加一个「快速模式」开关，打开后跳过意图路由与汇总，由单个挂载了院内知识检索与联网检索的 Agent 直接流式回答。

**Architecture:** 新增一张与现有图并列的 `fast_graph`：`START → fast_node → summarize_node → END`。`fast_node` 是**根图节点**，在节点内部自己跑工具循环（`model.bind_tools` + 手写 tool loop），因此它的模型分片带空的子图命名空间，能被 SSE 路由直接逐字转发。两张图共用同一个 `State`、同一个 `conversationId` 作为 `thread_id`，因此会话记忆在两种模式之间连续。请求通过新增的 `fastMode` 布尔字段选图，链路为 前端开关 → Java `aiRequest.fastMode` → Python `ChatRequest.fast_mode` → `_graph_for()`。

**Tech Stack:** Python 3.11+ / FastAPI / LangGraph 1.2.10 / langchain 1.3.14 / langgraph-checkpoint-redis 0.5.2 / Qdrant / Tavily / Spring Boot / Vue 3 / pytest

## Global Constraints

- 快速模式**只挂两个工具**：`search_hospital_knowledge`（院内 Qdrant）与 `web_search`（Tavily）。**不得**挂载 `list_departments`、`list_doctors`、`list_schedules`、`list_my_registrations`。患者问排班、号源、我的预约时，由提示词引导其关闭快速模式，不得编造医院实时数据。
- 快速模式**不做任何写操作**，不挂号、不退号、不缴费。
- 院内 RAG 以**工具**形式接入，由模型自主决定是否调用；不做每轮强制前置检索。
- 快速模式与正常模式**共用 `thread_id`**（即 `conversationId`），记忆连续。Task 1 未通过时按其「失败回退」小节改为独立 thread。
- `fast_node` 必须是根图节点，模型调用必须发生在该节点内部。**不得**把 `create_agent` 编译结果作为节点加进图——那会成为子图，其分片被 `app/api/routes/chat.py` 的 `if part.get("ns"): continue` 过滤掉，快速模式将完全丧失流式。
- 委托令牌只能存在于 `HospitalToolContext` 运行时上下文，**不得**写入 State 或 checkpoint。
- 工具循环产生的中间 `AIMessage`（含 tool_calls）与 `ToolMessage` **不得**写回 State，只把最终答案作为一条 `AIMessage` 写入 `messages`。这保证快速模式与正常模式的 checkpoint 结构一致。
- 所有新增/修改的测试必须用 `python -m pytest` 在 `ai-python` 目录下跑通，不得引入真实 Redis、真实 Qdrant、真实 Tavily 或真实 LLM 调用。
- 未配置 `TAVILY_API_KEY` 时 `web_search` 返回无命中提示而非抛错，此行为已存在，不要改动。

```python
class _StreamingStubModel:
    def __init__(self, reply):
        self.reply = reply

    def stream(self, messages):
        yield AIMessage(content=self.reply)


def _spike_fast_graph(checkpointer):
    """与计划中的快速模式同形：单个根节点写 final_reply，后接共用的 summarize_node。"""

    def spike_node(state: State) -> dict:
        reply = "快速模式回复"
        return {"final_reply": reply, "messages": [AIMessage(content=reply)]}

    workflow = StateGraph(State, context_schema=HospitalToolContext)
    workflow.add_node("fast_node", spike_node)
    workflow.add_node("summarize_node", summarize_node)
    workflow.add_edge(START, "fast_node")
    workflow.add_edge("fast_node", "summarize_node")
    workflow.add_edge("summarize_node", END)
    return workflow.compile(checkpointer=checkpointer)


def test_fast_and_normal_graphs_resume_the_same_thread(monkeypatch):
    monkeypatch.setattr(
        begin_module, "_classify", lambda messages: '{"selected_agents":["chat"]}'
    )
    monkeypatch.setattr(chat_module, "model", _StreamingStubModel("正常模式回复"))

    saver = InMemorySaver()
    normal = graphs.build_graph(checkpointer=saver)
    fast = _spike_fast_graph(saver)

    normal.invoke(

        context=CONTEXT,
        config=CONFIG,
    )

        "快速模式回复",
```

```python
"""院内 RAG 文档的展示格式化。只做纯转换，不检索、不调模型。"""

from langchain_core.documents import Document


def format_rag_context(documents: list[Document], start: int = 1) -> str:
    """把检索结果转成模型可读的院内资料上下文。start 用于多次检索时接续编号。"""

    blocks: list[str] = []
    for index, document in enumerate(documents, start=start):
        metadata = document.metadata or {}
        title = (
            metadata.get("source_name") or metadata.get("originalName") or "院内知识库"
        )
        page = metadata.get("page") or metadata.get("pageNumber") or "未标注"
        blocks.append(
            f"[S{index}] 来源：{title}；页码：{page}\n{document.page_content}"
        )
    return "\n\n".join(blocks)


def to_rag_sources(documents: list[Document], start: int = 1) -> list[dict]:
    """提取引用来源元数据，编号与 format_rag_context 保持一致。"""

    sources: list[dict] = []
    for index, document in enumerate(documents, start=start):
        metadata = document.metadata or {}
        sources.append(
            {
                "id": f"S{index}",
                "document_id": metadata.get("document_id")
                or metadata.get("documentId"),
                "title": metadata.get("source_name") or metadata.get("originalName"),
                "page": metadata.get("page") or metadata.get("pageNumber"),
            }
        )
    return sources
```

```python
"""院内知识库检索工具。供快速模式的单 Agent 自主调用。"""

from langchain.tools import tool
from langchain_core.documents import Document
from loguru import logger

from app.rag.documents import format_rag_context
from app.rag.qdrant import get_hospital_retriever


def retrieve_hospital_documents(query: str) -> list[Document]:
    """检索院内知识库。空 query 或后端故障时返回空列表，不把异常抛给模型。"""

    if not query.strip():
        return []
    try:
        return get_hospital_retriever().invoke(query)
    except Exception:
        logger.exception("hospital_knowledge_retrieval_failed")
        return []


@tool
def search_hospital_knowledge(query: str) -> str:
    """检索温润诊所院内知识库，内容包括就诊须知、院内规定和院方发布的科普资料。

    query 必须是整理后的短检索词，不要传入患者原话全文。
    """

    documents = retrieve_hospital_documents(query)
    if not documents:
        return "（院内知识库无命中。）"
    return format_rag_context(documents)
```

```python
def _stream_turn(bound_model, messages) -> tuple[AIMessageChunk | None, str]:
    """跑一轮模型。返回聚合后的分片（用于读 tool_calls）与纯文本。

    用 stream 而非 invoke，分片才能被 LangGraph 的 messages 流立即转发给 SSE 路由。
    """

    aggregated: AIMessageChunk | None = None
    parts: list[str] = []
    for chunk in bound_model.stream(messages):
        aggregated = chunk if aggregated is None else aggregated + chunk
        content = getattr(chunk, "content", "")
        if isinstance(content, str) and content:
            parts.append(content)
    return aggregated, "".join(parts)


def _run_tool_call(call: dict, collected: list[dict]) -> str:
    """执行一次工具调用。院内检索走底层函数，以便同时收集引用来源。"""

    name = call.get("name")
    args = call.get("args") or {}

    if name == search_hospital_knowledge.name:
        documents = retrieve_hospital_documents(str(args.get("query") or ""))
        if not documents:
            return "（院内知识库无命中，可改用 web_search 查询公开资料。）"
        start = len(collected) + 1
        collected.extend(to_rag_sources(documents, start=start))
        return format_rag_context(documents, start=start)

    if name == web_search.name:
        return web_search.invoke(args)

    logger.warning("fast_node_unknown_tool name={}", name)
    return f"（没有名为 {name} 的工具，请直接回答或改用其他工具。）"


def fast_node(state: State) -> dict:
    bound_model = model.bind_tools(FAST_TOOLS)
    messages = [SystemMessage(content=FAST_SYSTEM_PROMPT), *recent_messages(state)]
    collected: list[dict] = []
    text = ""

    for _ in range(MAX_TOOL_ITERATIONS):
        reply, text = _stream_turn(bound_model, messages)
        tool_calls = getattr(reply, "tool_calls", None) if reply is not None else None
        if not tool_calls:
            break
        messages.append(reply)
        for call in tool_calls:
            messages.append(
                ToolMessage(
                    content=_run_tool_call(call, collected),
                    tool_call_id=call.get("id") or "",
                )
            )
    else:
        # 工具预算耗尽仍在调工具：去掉工具再问一次，逼出一个面向患者的答案。
        logger.warning(
            "fast_node_tool_budget_exhausted conversation_id={}",
            state.get("conversation_id"),
        )
        _, text = _stream_turn(model, messages)

    final_reply = text.strip() or EMPTY_REPLY_FALLBACK
    # 工具循环里的中间消息不写回 State：checkpoint 结构必须与正常模式保持一致。
    return {
        **reset_turn_fields(),
        "final_reply": final_reply,
        "rag_sources": collected,
        "messages": [AIMessage(content=final_reply)],
    }
```

## 已知取舍与遗留问题

实现完成后，这些是**明知且接受**的行为，不要当成 bug 去修：

- **工具调用前的开场白会闪一下。** 模型在决定调工具的那一轮如果先吐了「我查一下院内资料」这类文本，它会被流式发给患者；等 `done` 事件到达时前端用 `done.reply` 覆盖正文，这段开场白会消失。这与 `create_agent` 的行为一致，属于流式与工具循环的固有矛盾。若实测中特别刺眼，再考虑在提示词里禁止「调工具的同一轮输出文本」。
- **快速模式答不了业务查询。** 这是 Global Constraints 里的显式决定，靠提示词引导患者关闭快速模式。
- **摘要节点仍在最后一轮之后同步执行。** 消息数超过 12 条时，`done` 事件会被摘要那一轮 LLM 调用拖慢。两种模式都有这个问题，不在本次范围内。
- **意图路由那一轮 LLM 在正常模式里依然存在。** 本计划只提供绕过它的第二条路径，没有优化它本身。
- **`rag_sources` 编号跨多次检索递增但不去重。** 同一轮里两次检索命中同一篇资料会产生两条来源。命中概率低，暂不处理。
